# Freelance software domain pack

Reserved for the first reusable configuration: freelance web development and
software entrepreneurship. It may select Leads, Current, Recallatron, relationships,
and optional job-search/proposal capabilities through the eventual module contract.

Keep templates, vocabulary, and defaults generic. Personal biographies, resumes,
rates, portfolios, client lists, private prompts, and connection details belong in
private workspace overrides. This directory contains no real user's configuration
and does not yet define a frozen pack schema.

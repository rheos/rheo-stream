# Requirements

Scoped requirements, decisions, and acceptance criteria derived from the
[idea document](../ideas/rheo-stream-idea.md).

- [Requirements and scope](requirements-and-scope.md): the settled decisions and their
  rationale, the recorded changes of direction, numbered functional requirements, the
  release-one scope boundary, the user interface port inventory, edge cases, assumptions,
  and the disposition of every open question the idea document left.
- [Build plan](build-plan.md): the phased plan, with per-phase goals, scope boundaries, and
  numbered acceptance criteria traced to the idea document's architecture acceptance
  scenarios.

Release one is the first three phases: a walking skeleton, the memory module, and the
opportunity core. It begins with one useful reference configuration and explicit checks for
custom funnels, private-data placement, and module boundaries. Full products for multiple
professions, and the full module lifecycle, are later scope.

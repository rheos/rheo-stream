# Architecture

Reserved for specifications and architecture decision records derived from the
[idea document](../ideas/rheo-stream-idea.md).

Open decisions include the module manifest and capability contracts, domain
schemas, event and MCP contracts, the identifier scheme, the model-provider
redaction contract, pipeline preset configuration limits, and data-lifecycle
detail beyond the first release. The implementation stack, the storage topology,
the minimum relationships contract, and how much of the module contract the first
release implements are settled in the
[requirements and scope](../requirements/requirements-and-scope.md) as proposals
awaiting the maintainer's ratification, not as accepted architecture. Keep
accepted decisions distinguishable from proposals, with rationale and
implications for existing contracts. No architecture specifications exist yet.

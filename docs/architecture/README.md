# Architecture

Reserved for specifications and architecture decision records derived from the
[idea document](../ideas/rheo-stream-idea.md).

Open decisions include the module manifest and capability contracts, domain
schemas, event and MCP contracts, the identifier scheme, the model-provider
redaction contract, pipeline preset configuration limits, and data-lifecycle
detail beyond the first release. The
[requirements and scope](../requirements/requirements-and-scope.md) records the
implementation stack, the storage topology, and how much of the module contract
the first release implements as directions the maintainer already gave, and
proposes five further decisions, the minimum relationships contract among them,
that await the maintainer's ratification. None of it is accepted architecture:
the architecture specification designs against those decisions and is still to be
written. Keep accepted decisions distinguishable from proposals, with rationale
and implications for existing contracts. No architecture specifications exist
yet.
